# TikTok Race

A phone-friendly, landscape-first racing game demo for a TikTok LIVE-style stream.

## Run it
Open `index.html` in a browser, or enable GitHub Pages:
1. Open the repository Settings.
2. Open Pages.
3. Choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. Open the Pages URL GitHub provides.

## Demo controls
- LIKE adds a small acceleration boost to featured driver `@laura_8086`.
- Rose, Galaxy and Lion buttons add larger simulated nitro boosts.
- The leaderboard, speed, progress and remaining distance update during the race.

## Important
This is a standalone simulation. It does not connect to TikTok LIVE or receive real viewer likes/gifts. Real event integration requires a supported and authorized event source. The cars and branding are generic and are not affiliated with Formula 1 or TikTok.
